# ApiArk 0.4.7

This is the first macOS release of the maintained fork.
The universal DMG supports Apple Silicon and Intel Macs.
The application and DMG use Developer ID signing and Apple notarization.
Both include a notarization ticket, which lets Gatekeeper assess them without a separate ticket download.

## Install

Download `ApiArk-0.4.7-macos-universal.dmg` from this release.
Open the DMG, then drag `ApiArk.app` to Applications.
The `SHA256SUMS.txt` file contains the download checksum.
Automatic updates are disabled. Download later releases from GitHub.

## Changes from upstream 0.4.6

- The macOS desktop and CLI share the HTTP, collection, script, test, and Postman implementation.
- Script errors and failed tests return a nonzero CLI exit code.
- `ark.visualize` supports image, text, and JSON outputs for each request.
- Variable suggestions show names without sensitive values.
- Postman Collection v2.1 import and export preserve scripts and report compatibility limits.
- Cookie, redirect, import, history, script, and response limits include regression tests.
- The desktop uses a dark macOS title bar with native window controls.
- The bundle identifier is `dev.kepak.apiark`. Application data stays in `~/.apiark-internal`.
- The fork removes web, AI, plugins, specialized protocols, monitoring, mock servers, and the original updater.

## Limits

The Postman `pm.*` runtime is not implemented. Adapt imported scripts to `ark.*` before use.
The fork focuses on HTTP/REST. The desktop runs only on macOS.
The application buffers responses up to 10 MiB. It rejects larger responses.
The release does not migrate data from the original application.
The MIT license and original copyright notices remain in the source and application bundle.

The release assets include a build record with the source commit, test results, and notarization submission identifiers.
